# Komerce WooCommerce Plugin - Official Releases

Repository ini khusus mendistribusikan file release resmi (.zip) untuk Komerce WooCommerce Plugin.
Source code development dikelola secara privat oleh tim internal Komerce.

### Download & Instalasi
1. Unduh file **komerce-woocomerce.zip** dari tab [Releases](https://github.com/Ikhsandi15/rajawp-plugin-release/releases) atau file di repository ini.
2. Buka WordPress Admin: **Plugins → Add New Plugin → Upload Plugin**.
3. Pilih file komerce-woocomerce.zip dan klik **Install Now**.
4. Update selanjutnya dapat dilakukan dengan **1-click update** langsung dari dashboard WordPress.
